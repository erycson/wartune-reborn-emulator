# Servidor Wartune

## Progresso: `docs/progresso.md`

- É o **único** arquivo de progresso. Toda pergunta sobre progresso ("o que falta", "o que é turco", "o que é
  inventado", "como estamos") se responde por ele.
- Atualizar sempre, no mesmo commit da mudança: sistema que muda de status muda a linha; sistema novo vira linha
  nova na categoria certa. Depois, `python tools/progresso_totais.py` para os totais.
- Nunca duplicar: não criar outro arquivo de pendências, plano, roadmap ou checklist. Detalhe (pacotes, ordem,
  fontes, o que capturar) vai no MD da categoria em `docs/` ou no código, não no progresso.
- Colunas: Inglês ✅ 🟡 🧪 ❌; Turco 🇹🇷 só quando o turco cobriu o que falta no inglês.
