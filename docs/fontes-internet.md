# Fontes da Internet

O que não está no tempinfos.xml, no cliente nem nas capturas, achado na web e conferido por um segundo
agente que abriu cada página. Só entram os achados confirmados (`verified`). No código, cite como
`(internet) <URL>`. Ordem de confiança das fontes: captura > cliente > templates > Internet > dedução.

Os guias são da versão em inglês (Kabam/R2Games): os nomes não batem com os turcos dos templates; a
ligação nome inglês -> TemplateId é feita por nível, classe e tipo do item.

O fandom (wartune.fandom.com) bloqueia a página comum (HTTP 402); a leitura foi pela API:
`https://wartune.fandom.com/api.php?action=parse&page=<Página>&prop=wikitext&format=json`.
